# Removed deliberately:
#   black, isort, flake8 - dev-only formatters/linters that had leaked into this
#                  *runtime* file, and all three are superseded by ruff==0.16.0
#                  (pinned in requirements-dev.txt, which mast-clone installs
#                  alongside this file). ruff.toml already enables their rule
#                  sets: "I" is isort, "B"/"SIM" are flake8-bugbear/-simplify,
#                  and the formatter is Black-compatible. Nothing in the repo or
#                  CI invokes the three tools; no setup.cfg/.flake8/.isort.cfg
#                  exists. Keeping them here shipped three redundant linters to
#                  every unit machine.
#   ipaddress    - the PyPI *backport*, which shadows the stdlib module (stdlib
#                  since Python 3.3; this file targets py312). Same trap as the
#                  pathlib backport removed from MAST_spec/requirements.txt. The
#                  two import sites -- src/common/networking.py and src/unit.py
#                  -- both want the stdlib.
#   pydantic     - was listed three times (identical ==2.13.4 pins); kept once,
#                  in the alphabetical block above.
#   setuptools   - a `pip freeze` artifact, not a dependency. Nothing in this
#                  repo imports setuptools, pkg_resources or distutils, and
#                  nothing in the resolved dependency tree needs it at runtime.
#                  Note that `uv venv` does not seed it, so if some future
#                  dependency turns out to import pkg_resources on the units,
#                  this is the line to restore.
#
